# Fuentes locales

Servidas con `next/font/local` desde `src/app/layout.tsx`, para que el build no dependa de la red (#31).
Son las variantes variables (eje de peso, subconjunto latin) de los paquetes `@fontsource-variable/*` 5.3.0.
Las tres se distribuyen bajo SIL Open Font License 1.1 (texto en `LICENCIA-*.txt`).

- Inter (Inter Project Authors)
- Source Serif 4 (ver LICENCIA-source-serif-4.txt)
- JetBrains Mono (JetBrains)
